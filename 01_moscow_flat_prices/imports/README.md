# Внешние файлы импорта

Файлы, которых нет в исходных данных конкурса. Каждый создаётся служебной тетрадью из `../service/`, а основная тетрадь только читает готовый файл.

| Файл | Что внутри | Откуда | Как используется |
|---|---|---|---|
| `district_coords.csv` | Координаты центра для каждого из 120 районов: `District, lat, lon, source` | Английская Википедия: 115 районов. Ещё 5 взяты по карте, у них `source = manual`. Тетрадь `service/collect_district_coords.ipynb` | Признаки «расстояние до центра (Кремля)», «направление от центра», широта и долгота района |
