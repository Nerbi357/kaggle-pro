# kaggle-pro

Решения четырёх соревновательных задач по машинному обучению.

| # | Папка | Задача |
|---|---|---|
| 1 | [`01_moscow_flat_prices`](01_moscow_flat_prices) | Стоимость квартир: оценка стоимости квартир в Москве |
| 2 | [`02_company_bankruptcy`](02_company_bankruptcy) | Банкротство компаний: определение банкротства по финансовой отчётности |
| 3 | [`03_hospital_procurement_fraud`](03_hospital_procurement_fraud) | Закупочная деятельность больниц: определение подозрительной активности в закупках |
| 4 | [`04_procurement_winner`](04_procurement_winner) | Закупки (победитель): определение выигравшей закупки |

Каждый проект устроен одинаково: `data/` — данные, `experiments/` — черновые эксперименты, `submissions/` — предсказания, `README.md` — план и журнал решений, `solution.ipynb` — финальная тетрадь.
